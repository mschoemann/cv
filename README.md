# cv_mschoemann

Curriculum Vitae of Martin Schoemann.

View and download it [here](https://mschoemann.github.io/cv/cv_mschoemann.pdf).

Semi-automated with Quarto, R, bash, and Google Sheets; with props to John P. Helveston ([jhelvy](https://github.com/jhelvy)).

Document automatically renders every Friday, 8pm (UTC), by GitHub action based on information taken from manually curated Google Sheets and automatically scraped Google Scholar.
Scraping of Google Scholar is realize locally via systemd-timed bash script (not hosted here).
